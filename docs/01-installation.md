# Installation

This chapter describes how to install `git-reflow` on your system.

## 🦀 Cargo

```shell
cargo install --locked git-reflow
```

### Feature flags

- `bitbucket` - Bitbucket provider support
- `github` - GitHub provider support

**Default features:** `github`, `bitbucket`.

## 🐍 Python

### via [uv]

```shell
uv tool install git-reflow-rs
```

### via [pip]

```shell
pip install git-reflow-rs
```

[pip]: https://pypi.org/p/git-reflow-rs
[uv]: https://docs.astral.sh/uv
